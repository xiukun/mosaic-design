## 新增需求

### 需求:图片居中计算
系统必须正确计算图片在占位符中的居中偏移量，确保图片在裁剪区域内居中显示。

#### 场景:横向图片居中
- **当** 上传一张宽高比大于占位符宽高比的图片时
- **那么** 图片应水平居中，左右超出部分被裁剪

#### 场景:纵向图片居中
- **当** 上传一张宽高比小于占位符宽高比的图片时
- **那么** 图片应垂直居中，上下超出部分被裁剪

#### 场景:等比例图片居中
- **当** 上传一张宽高比等于占位符宽高比的图片时
- **那么** 图片应完全填满占位符，无偏移

### 需求:模板应用时图片居中
系统必须确保通过模板应用功能添加的图片在占位符中正确居中。

#### 场景:应用模板时图片居中
- **当** 用户选择模板并点击"应用模板"按钮时
- **那么** 所有已上传的图片应在对应的占位符中居中显示

### 需求:图片上传时居中
系统必须确保通过占位符点击上传的图片在占位符中正确居中。

#### 场景:点击占位符上传图片
- **当** 用户点击占位符并选择图片上传时
- **那么** 上传的图片应在占位符中居中显示

## 修改需求

### 需求:图片位置计算逻辑
`calculateImageFit` 函数必须计算正确的居中偏移量。

#### 场景:偏移量计算
- **当** 调用 `calculateImageFit` 函数时
- **那么** 返回的 `offsetX` 和 `offsetY` 必须等于 (占位符尺寸 - 缩放后图片尺寸) / 2

### 需求:模板应用时的图片位置计算
`useTemplateApplication` 中的 `calculateImageFit` 函数必须计算正确的居中偏移量。

#### 场景:模板应用时的偏移量计算
- **当** 应用模板并分配图片到占位符时
- **那么** 计算出的偏移量必须使图片居中显示
