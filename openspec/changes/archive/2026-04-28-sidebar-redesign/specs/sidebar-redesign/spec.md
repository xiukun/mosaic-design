# 侧边栏重构功能规范

## 用户故事

作为用户，我希望有更简洁的界面布局，这样我可以在更大的画布上进行设计操作。

## 验收标准

### 可折叠的垂直图标侧边栏
- [ ] 默认显示 56px 宽度的左侧栏，只显示垂直排列的图标
- [ ] 点击图标可展开到 240px 宽度，显示完整面板
- [ ] 再次点击同一图标会收起面板
- [ ] 同一时间只能展开一个面板
- [ ] 图标有选中状态（高亮

### 左侧栏面板内容
- [ ] 模板面板：显示模板选择器
- [ ] 图库面板：显示图片上传器
- [ ] 布局面板：整合画布尺寸、布局类型、网格设置、间距和圆角
- [ ] 背景面板：显示背景设置

### 网格布局预设按钮
- [ ] 在网格布局设置中显示常用预设按钮
- [ ] 预设包括：1x1、2x2、3x3、3x2、2x3、4x4
- [ ] 点击预设按钮会立即应用

### 选中图片的浮动工具栏
- [ ] 当点击选中图片时，显示浮动工具栏
- [ ] 工具栏包含：旋转按钮、删除按钮
- [ ] 工具栏位置：图片上方居中
- [ ] 样式：半透明、圆角、带阴影

### 画布区域最大化
- [ ] 移除右侧栏，画布区域占满剩余空间

## 依赖关系

无额外依赖，基于现有组件重构。
