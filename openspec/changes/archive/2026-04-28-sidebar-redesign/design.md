# 侧边栏重构设计文档

## 上下文

当前布局有两个侧边栏（LeftSidebar + RightSidebar），占用了太多空间。右侧栏有 3 个 Tab（尺寸、布局、样式），需要频繁切换，操作不流畅。

## 目标 / 非目标

### 目标
- 最大化画布空间（移除右侧栏）
- 更直观的垂直图标导航（参考 FotoJet）
- 可折叠的侧边栏面板
- 选中图片时有浮动工具栏

### 非目标
- 不添加新功能（除了布局预设按钮
- 不改变状态管理逻辑
- 不重构核心功能

## 决策

### 决策 1：垂直图标导航
- 选项 A：保持 Tab 切换
- 选项 B：垂直图标，可折叠（推荐

原因：专业工具的常见模式，给画布更多空间

### 决策 2：单侧边栏架构
- 选项 A：保留左右双栏
- 选项 B：只保留左侧栏，右侧完全移除（推荐

原因：最大化画布，减少复杂度

### 决策 3：浮动工具栏
- 选项 A：把图片操作放侧边栏
- 选项 B：选中图片时显示浮动工具栏（推荐

原因：上下文感知，操作更快捷

## 风险 / 权衡

| 风险 | 缓解措施 |
|------|----------|
| 侧边栏逻辑复杂 | 分拆为小组件，清晰的状态管理 |
| 过渡动画卡顿 | 优化 CSS 动画，使用 transform |
| 用户习惯改变 | 保持功能位置逻辑一致，学习成本低 |

## 迁移计划

1. 重构 LeftSidebar 为垂直图标
2. 整合现有组件到左侧面板
3. 移除 RightSidebar
4. 实现浮动工具栏
5. 完整测试
