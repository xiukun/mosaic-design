## 上下文

当前系统已有间距调整功能，但仅在网格布局下可用。图片圆角是硬编码的（`Math.max(4, Math.min(16, img.scale*8))`），无法自定义。LayoutConfig 类型已包含 `spacing` 字段，需要添加 `borderRadius` 字段。

## 目标 / 非目标

**目标：**
- 使间距调整在所有布局下可用
- 添加可配置的圆角调整功能
- 确保所有调整具有实时预览效果
- 保持向后兼容性

**非目标：**
- 重构现有布局算法（除非必要）
- 添加其他视觉效果（阴影、滤镜等）
- 创建新的组件（复用现有 LayoutSelector）

## 决策

### 决策 1：将圆角添加到 LayoutConfig 而非 CanvasConfig
**替代方案：**
- 方案 A：放在 CanvasConfig（影响整个画布）
- 方案 B：放在 LayoutConfig（影响布局中的图片）✓

**理由：** 圆角是图片布局的视觉属性，更适合与其他布局参数（间距、行列数）放在一起。

### 决策 2：百分比单位而非像素
**替代方案：**
- 方案 A：像素单位（绝对尺寸）
- 方案 B：百分比单位（相对尺寸）✓

**理由：** 百分比单位更适合响应式设计，在不同画布尺寸下效果一致。

### 决策 3：在 LayoutSelector 中添加控件，而非创建新组件
**替代方案：**
- 方案 A：创建新的 LayoutAdjustControls 组件
- 方案 B：扩展现有 LayoutSelector 组件✓

**理由：** 功能紧密相关，放在一起用户体验更连贯，减少组件数量。

## 风险 / 权衡

| 风险 | 缓解措施 |
|------|----------|
| 性能：频繁重绘可能导致卡顿 | 使用 React 状态更新的自然批处理，无需额外防抖 |
| 向后兼容性：新字段可能破坏现有代码 | 为新字段提供默认值，保持类型可选 |
| 不同布局类型的间距行为不一致 | 统一在 layoutAlgorithms 中处理间距逻辑 |

## 迁移计划

1. 更新类型定义和默认值
2. 更新 LayoutSelector 添加控件
3. 更新 CanvasEditor 使用可配置圆角
4. 确保所有布局算法使用间距参数
5. 测试所有功能
