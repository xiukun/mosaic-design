## 新增需求

### 需求:间距调整适用于所有布局
系统必须允许用户在所有布局类型（网格、马赛克、自由）下调整图片间距。

#### 场景:网格布局下调整间距
- **当** 用户在网格布局下拖动间距滑块
- **那么** 图片间距立即更新，布局重新计算

#### 场景:马赛克布局下调整间距
- **当** 用户在马赛克布局下拖动间距滑块
- **那么** 图片间距立即更新

#### 场景:自由布局下调整间距
- **当** 用户在自由布局下拖动间距滑块
- **那么** 布局配置更新（后续重新布局时生效）

### 需求:圆角调整
系统必须允许用户调整所有图片的圆角大小。

#### 场景:调整圆角滑块
- **当** 用户拖动圆角滑块
- **那么** 所有图片的圆角立即更新

#### 场景:圆角范围限制
- **当** 用户将圆角设置为 0
- **那么** 图片显示为直角

#### 场景:圆角最大值限制
- **当** 用户将圆角设置为 100
- **那么** 图片显示为最大可能的圆角（圆形或椭圆）

### 需求:实时预览
系统必须在用户调整控件时立即反映变化，无需额外确认操作。

#### 场景:滑块拖动实时更新
- **当** 用户拖动间距或圆角滑块
- **那么** 画布立即更新以显示当前状态
