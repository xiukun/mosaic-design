# 模板管理功能规范

## 功能概述
模板管理功能允许用户管理模板的收藏和历史记录，提高用户体验和使用效率。

## 功能需求

### 1. 模板收藏
- 支持用户收藏喜欢的模板
- 显示用户收藏的模板列表
- 支持取消收藏模板

### 2. 模板历史
- 记录用户最近使用的模板
- 显示模板使用历史记录
- 支持从历史记录中快速应用模板

### 3. 模板搜索
- 支持按名称搜索模板
- 支持按分类筛选模板
- 支持按热门程度排序模板

- `TemplateManager` 组件：处理模板管理逻辑
- `TemplateFavorites` 组件：显示用户收藏的模板
- `TemplateHistory` 组件：显示用户使用过的模板
