# 模板应用功能规范

## 功能概述
模板应用功能允许用户将选中的模板应用到画布，自动调整画布尺寸并分配图片到模板的占位符。

## 功能需求

### 1. 模板应用
- 支持一键应用模板到画布
- 应用模板时自动调整画布尺寸和布局
- 保留已上传的图片，智能分配到模板的占位符

### 2. 图片分配
- 基于图片比例和大小智能分配图片到占位符
- 支持手动调整图片位置和大小
- 当图片数量不足时，显示占位符提示用户添加图片

### 3. 画布调整
- 根据模板配置自动调整画布尺寸
- 应用模板的背景设置
- 保持画布的响应式布局
