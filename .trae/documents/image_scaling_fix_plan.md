# 图片缩放和定位修复计划

## 问题分析

用户反馈图片大小不正确，没有正确填充到模板占位符中。经过代码分析，发现以下潜在问题：

1. **图片缩放算法**：当前使用的 cover 模式缩放算法可能存在问题
2. **图片定位逻辑**：图片位置计算可能不够准确
3. **Konva 渲染**：KonvaImage 组件的属性设置可能影响图片显示

## 修复方案

### 1. 优化图片缩放和定位算法

**文件**：`/src/components/CanvasEditor/CanvasEditor.tsx`

**修改点**：
- 重新实现 `handlePlaceholderClick` 函数中的图片缩放和定位逻辑
- 确保图片使用 cover 模式正确填充占位符
- 修正图片位置计算，确保图片居中显示

### 2. 调整 KonvaImage 组件属性

**文件**：`/src/components/CanvasEditor/CanvasEditor.tsx`

**修改点**：
- 确保 KonvaImage 组件的 width 和 height 属性正确设置
- 验证 scaleX 和 scaleY 属性的使用方式
- 确保图片渲染顺序正确

### 3. 测试和验证

**步骤**：
1. 启动开发服务器
2. 选择不同的模板
3. 上传图片到占位符
4. 验证图片是否正确缩放和定位
5. 测试删除图片功能
6. 测试图片拖动和调整大小功能

## 预期效果

- 图片应该完全覆盖占位符区域
- 图片应该保持原始宽高比
- 图片应该居中显示在占位符中
- 图片应该显示在占位符之上
- 图片应该可以正常删除和调整

## 风险评估

- **风险**：修改图片缩放算法可能影响现有功能
- **缓解措施**：确保修改只影响模板占位符的图片上传，不影响其他图片添加方式
- **测试**：在修复后进行全面测试，确保所有功能正常工作

## 时间估计

- 代码修改：15-20分钟
- 测试验证：10-15分钟
- 总计：25-35分钟
