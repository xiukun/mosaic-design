# 修复图片大小不正确的问题

## 问题分析

用户反馈图片大小不正确，没有生成到指定位置。通过分析代码，我发现以下可能的问题：

1. **缩放比例计算问题**：当前使用 `Math.max(scaleX, scaleY)` 来计算缩放比例，可能导致图片尺寸不符合预期
2. **位置计算问题**：图片位置计算可能有误差，导致图片没有正确显示在占位符中
3. **KonvaImage 渲染问题**：KonvaImage 组件的属性设置可能不正确

## 解决方案

### 1. 修复缩放比例计算
- 确保使用正确的缩放算法，保证图片完全填充占位符
- 考虑使用 `cover` 模式，确保图片覆盖整个占位符区域

### 2. 修复图片位置计算
- 确保图片居中显示在占位符中
- 考虑占位符的旋转角度

### 3. 优化图片渲染
- 确保 KonvaImage 组件的属性设置正确
- 验证图片的实际显示尺寸

## 实施步骤

1. **修改 CanvasEditor.tsx 文件**：
   - 优化 handlePlaceholderClick 函数中的缩放比例计算
   - 确保图片位置计算正确
   - 添加调试信息，验证计算结果

2. **测试验证**：
   - 测试不同大小的图片
   - 测试不同类型的模板
   - 确保图片正确填充到占位符中

3. **性能优化**：
   - 确保图片加载和渲染过程流畅
   - 优化状态更新逻辑

## 风险评估

- **风险**：修改缩放算法可能影响现有功能
- **缓解措施**：测试各种场景，确保兼容性
- **风险**：位置计算错误可能导致图片显示异常
- **缓解措施**：添加详细的调试信息，验证计算结果

## 预期效果

- 图片能够正确填充到占位符中
- 图片大小与占位符匹配
- 图片位置居中显示
- 整个过程流畅，无明显延迟
