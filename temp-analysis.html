🖼️ 模板布局问题分析

深度分析和最佳 MVP 方案

❌ 当前问题

1. 图片与占位符无绑定

图片拖动后就"脱离"了

2. 缺少图片裁剪

图片超出占位符，没有裁剪

3. 缩放逻辑混乱

// 当前代码同时使用：
width: img.width
height: img.height
scaleX: img.scale
scaleY: img.scale

// 造成计算混乱！

4. 检查逻辑简陋

// 只简单检查位置：
x >= placeholder.x && 
x <= placeholder.x + width

// 不验证尺寸、缩放、对齐！

✅ 最佳 MVP 方案

方案 A：极简方案

使用 Konva.Group 剪裁，不需要绑定关系

  • • 图片进入占位符时自动缩放到完全填充
  • • 使用 Group 实现超出部分剪裁
  • • 没有持续绑定，拖出就脱离

方案 B：绑定方案（推荐）

图片与占位符绑定，类似专业工具

  • • 图片有 `placeholderId` 字段
  • • 图片在占位符内无法拖出
  • • 双击或拖动占位符外部解除绑定

方案 C：完整方案

类似 FotoJet 的完整布局引擎

  • • 智能填充和对齐
  • • 图片裁剪、旋转、对齐
  • • 复杂度高，超出 MVP

📋 推荐方案详情

1. 更新数据结构

interface ImageItem {
  id: string;
  placeholderId?: string;  // 新增：绑定的占位符
  // ... 其他字段
}

2. 核心交互流程

1️⃣ 上传

上传图片后自动分配到空闲占位符

2️⃣ 绑定

图片在占位符内，设置 placeholderId

3️⃣ 拖动

绑定的图片限制在占位符边界内

4️⃣ 裁剪

使用 Group 超出部分自动隐藏

3. 关键组件改动

  • CanvasEditor：使用 Group 实现裁剪
  • useTemplateApplication：分配时设置 placeholderId
  • isImageInPlaceholder：增强检测逻辑
